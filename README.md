# Дашборд личной продуктивности

Одностраничное приложение на чистом JavaScript с ES6-модулями и ООП.

## Запуск

```bash
npx serve .
```

Откройте адрес, который покажет сервер, например `http://localhost:3000`.

## Архитектура

- `UIComponent` — базовый класс: рендер, свернуть/закрыть, удаление слушателей, интервалов и запросов.
- `ToDoWidget` — локальный список задач.
- `QuoteWidget` — локальные цитаты.
- `WeatherWidget` — данные Open-Meteo API.
- `CurrencyWidget` — данные Frankfurter API.
- `Dashboard` — коллекция виджетов, добавление и удаление.

## API

- Open-Meteo: погода в Москве, без ключа.
- Frankfurter: курсы валют, без ключа.

## Безопасность и UX

- Ответы API вставляются только через `textContent`.
- Каждый запрос можно отменить через `AbortController`.
- Есть состояния загрузки, ошибки и пустого результата.
- Все действия доступны с клавиатуры, фокус видим.
